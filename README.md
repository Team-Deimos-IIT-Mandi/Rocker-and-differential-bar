# 🚀 Rocker & Differential Bar

This repository contains CAD files, renders, and documentation for two essential subsystems of a Mars Rover: the **Rocker** and the **Differential Bar**.  
These components form the backbone of the rover’s suspension system, enabling stability, balance, and effective traversal over rough terrain.

---

## 🪨 Rocker

The **Rocker** is a suspension component that connects the rover wheels on one side to the chassis.  
It allows the rover to maintain stability when navigating rocks, slopes, and uneven ground by distributing the load evenly.

### 🔧 Features
- Strong and lightweight structure  
- Provides vertical articulation for wheel movement  
- Designed to handle uneven terrain without compromising rover stability  
- Mounting points for wheels and differential bar

## ⚖️ Differential Bar

The **Differential Bar** connects the two rockers (left and right) and ensures the rover maintains balance.  
When one rocker moves up, the differential bar transfers motion so the other rocker adjusts, keeping the main chassis level.

### 🔧 Features
- Connects both rockers into a stable system  
- Balances the rover body during uneven wheel movement  
- Critical for smooth navigation in rocky or sloped terrain  
- Strong mechanical design for long-term durability
