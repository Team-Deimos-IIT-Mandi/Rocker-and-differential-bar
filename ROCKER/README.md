## 🔍 Overview

This project presents a two-sketch mechanical design featuring a rocker joint system optimized for smooth operation and reduced mechanical stress. The design incorporates innovative material combinations and streamlined geometry to enhance performance in steering and chassis applications.

## 🔧 System Components

### 1. Rocker Joint Assembly

**Material**: Metal (adaptable shape and size based on application requirements)

**Components**:
- **Outer Hub**: Primary mounting interface
- **Shaft**: Central rotating element
- **Bearings**: Precision components for smooth rotation
- **Retaining Rings**: Secure component positioning
- **Support Plates**: Structural reinforcement
- **Nut & Bolt**: Fastening hardware

**Key Features**:
- ✅ Smooth rocker joint functioning
- ✅ Negligible cantilever load on shaft
- ✅ Seamless revolution around joint axis
- ✅ Reduced friction and wear

### 2. Rocker Bar (Links)

**Material Innovation**: **PLA + Resin + Metal** composite
> 🆕 **New Design Approach**: This innovative material combination provides enhanced strength-to-weight ratio while maintaining flexibility and durability.

**Purpose**:
- Primary connection interface between steering system and chassis
- Load distribution and force transmission

**Design Features**:
- **Streamlined Profile**: Optimized for reduced drag and improved aesthetics
- **Angular Configuration**: Strategic angle between two links for enhanced mechanical advantage
- **Lightweight Construction**: Advanced material combination reduces overall system weight

### 3. Glider/Support Guide System

**Material**: Metal construction for maximum durability

**Components**:
- **Support Shaft**: Primary structural element
- **Joint Roller**: Smooth operation interface
- **Chassis Slot**: Integrated mounting solution

**Primary Functions**:
- 🎯 **Chassis Support**: Provides essential structural support to the chassis framework
- 🎯 **Moment Reduction**: Significantly reduces overall net bending moment in the rocker shaft
- 🎯 **Load Distribution**: Optimizes force distribution across the system

## 📥 Installation

1. **Preparation**
2. **Assembly Sequence**
- Install bearing assemblies in outer hub
- Insert shaft through bearing system
- Secure with retaining rings
- Attach support plates
- Connect rocker bars with proper angular alignment
- Install glider/support guide system in chassis slot

3. **Verification**
- Check all fasteners for proper torque
- Verify smooth rotation of all moving parts
- Test angular movement within design parameters

## 💡 Usage

### Basic Operation
1. The rocker joint provides smooth rotational movement
2. Rocker bars transfer forces between steering and chassis
3. Support guide system maintains structural integrity during operation

### Maintenance
- Regular lubrication of bearing surfaces
- Periodic inspection of composite rocker bars
- Check fastener tightness according to schedule
